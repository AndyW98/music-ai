# Hindsight memory (optional)

Hindsight is the preferred long-term memory for this workflow when the user has already configured it. It is not required to transcribe audio. Discover the available MCP tools and configured bank at runtime; do not assume another person's server name, address, credentials, or bank ID. The original setup used a case-sensitive `Music` bank.

## At the start of a run

1. Prefer exposed Hindsight MCP `recall` and `retain` tools. If absent, make one bounded attempt through the user's configured MCP client and endpoint. An HTTP response from the server root alone does not confirm that MCP works; check MCP tool discovery.
2. If the server or music bank is unavailable, continue without memory. Do not create a replacement bank, install a server, or expose one publicly during a transcription run.
3. Recall targeted preferences, the recording's previous project/version and latest comparison, and methods relevant to its texture, tempo, and notation. Verify important claims against current files and primary sources. Never use notes recalled from a published score to create an audio-only draft.

## After verified work

Retain concise findings: audio provenance, workflow-created project and Project Info version, settings, new render/report paths, observed comparison result and its limits, unresolved discrepancies, and source links for researched methods. Label proposals and hypotheses. Update stale findings instead of duplicating them. If a `retain` call is asynchronous, verify completion through its operation status or a later recall before reporting it saved.
